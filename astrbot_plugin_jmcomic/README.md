# 🎴 jm下载姬

> 一个为 AstrBot 打造的禁漫本子下载插件。装上就能用，卸了就清净。

> ⭐ **本插件改编自 [hect0x7/JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python)**，在此向原作者致以诚挚感谢。

---
## 简介

**jm下载姬** 让你在 QQ 里直接完成禁漫本子的搜索、查看榜单、下载与交付，全程无需打开网页。

- 关键词搜索本子，分页浏览
- 日榜 / 周榜 / 月榜 Top10 一键查看
- 下载后按你的口味交付：**长图 / ZIP 压缩包 / PDF 文档**
- 交付完自动清理服务器文件，不占磁盘
- 依赖完全自包含，装上即用，卸载即净
- 上游更新走**授权式**：查到新版先问你，你看过审查报告再决定装不装，不会自己动手

## ⚠️ 已知限制与反馈

本插件目前**并不完善**，可能存在未知 bug 或兼容性问题，请知悉：

## 安装与拉取

### 从 GitHub 拉取插件

方式一：克隆整个仓库（最简单，推荐）：

```bash
git clone git@github.com:lijix123/mengli-plugins.git
# 插件在 mengli-plugins/astrbot_plugin_jmcomic/
```

方式二：只拉取插件目录（稀疏检出，省流量）：

```bash
git clone --depth 1 --filter=blob:none --sparse git@github.com:lijix123/mengli-plugins.git
cd mengli-plugins
git sparse-checkout set astrbot_plugin_jmcomic
```

方式三：直接下载仓库 ZIP：
GitHub 仓库首页 → 绿色 `Code` 按钮 → `Download ZIP`，解压后取 `astrbot_plugin_jmcomic` 文件夹。

### 安装到 AstrBot

将 `astrbot_plugin_jmcomic` 整个文件夹放入 AstrBot 的插件目录（通常是 `<AstrBot>/data/plugins/`），然后在 AstrBot 管理后台启用插件即可。

### 依赖说明与手动安装

插件依赖分两部分：

1. **jmcomic 库**：已内嵌在插件 `vendor/` 目录中，无需手动安装，随插件自带。
2. **curl-cffi（加密通信组件）**：装在插件私有目录 `.deps/`。**2026-10-04 起不再自动安装**，改为授权式 —— 缺了插件会暂停工作并提示你，敲 `jm依赖` 走流程装上。

若想手动装，也可以：

```bash
# 进入插件目录后执行（请把 <插件路径> 换成实际路径）
pip install curl-cffi --target <插件路径>/.deps -i https://pypi.tuna.tsinghua.edu.cn/simple/
```

装完重启 AstrBot 或重载插件即可。依赖全部装在插件私有目录内，不污染系统 Python 环境，卸载插件时自动清理。

## 快速开始

装好插件后，在 QQ 里直接发消息即可（默认仅管理员可用，可在面板调整）。

| 命令 | 说明 | 示例 |
| --- | --- | --- |
| `搜本 <关键词> [页码]` | 搜索本子，每页 5 条 | `搜本 无望菜志` |
| `排行 [周/日/月]` | 查看对应榜单 Top10 | `排行 周` |
| `下本 <ID> [格式]` | 下载本子，格式支持 `长图` `zip` `pdf` | `下本 243484 长图` |
| `我的任务` | 查看自己的下载任务状态 | `我的任务` |
| `取消 <任务号>` | 取消自己的任务 | `取消 1` |

> 格式缺省时使用面板默认格式，默认 `长图`。

### 授权式更新命令

敲任意常规命令时会顺带**只读**查一次上游版本，有新版就在回复里提示一行。要真正更新，得走下面这几条：

| 命令 | 说明 |
| --- | --- |
| `jm更新` | 下载新版到临时目录并静态审查，**不安装**；审查报告发给你 |
| `jm安装` | 看过报告后确认安装。**审查有可疑项时会被拒绝** |
| `jm强制安装` | 审查报过可疑、但你确认要装时的唯一通道 |
| `jm跳过` | 跳过这一版，上游再出新版才重新问你 |
| `jm放弃` | 丢掉临时文件，内置版本一个字不动 |
| `jm依赖` | 列出 curl-cffi 本机现有版本 + PyPI 可选版本（都带发布日期） |
| `jm依赖 <版本号>` | 下载指定版本到临时目录并审查 |
| `jm依赖 装` | 确认后装进 `.deps/` |
| `jm依赖 放弃` | 丢掉临时文件 |

> 没有更新时敲这几个命令，会统一回一句「暂无更新，请不要用非常规指令」。

### 交付格式说明

- **长图**：整本拼接成一张竖图直接发到 QQ，长本自动分段发送，看着最方便。
- **ZIP**：原始高清图片打包，适合收藏存档。
- **PDF**：整本合成 PDF 文档，适合存书架。

## 授权式更新

**2026-10-04 起，插件不再自己装任何东西。** 原来的「每小时自动检查、发现新版自动覆盖」已经拆掉。

现在的逻辑：

- **只读检测**：敲任意常规命令时，顺带查一次上游版本号。10 分钟节流，断网静默跳过，绝不卡住命令。查到有新版，在回复末尾提示一行。
- **你来决定**：`jm更新` 下载到临时目录并跑静态审查，报告发给你；`jm跳过` 记下这版不再问；`jm安装` 才真正覆盖内置版本。
- **审查报可疑就不给装**：危险调用、陌生外联地址、安装期钩子 `.pth`、上传者换人，中哪条都算可疑，`jm安装` 会被拒，要装必须敲 `jm强制安装`。
- **私有依赖同理**：`curl-cffi` 也不再自动装，走 `jm依赖` 系列命令，装之前先列出可选版本（带发布日期）让你挑。

> 有一点说实话：审查是**读代码**，不是杀毒。服务器上没有杀毒引擎，也认不出「已知病毒」。
> 能查的是源码改动、文件清单、外联地址、安装期钩子、以及**和 PyPI 官方哈希比对**。
> `curl-cffi` 的核心是编译好的 `.so`，里面写了什么读不出来，那一环只能靠来源可信。

> 上游库由 hect0x7/JMComic-Crawler-Python 提供，更新逻辑仅同步该库源码，不引入其他代码。

## 更新日志

### v1.2.0（2026-10-04）

**把「自动更新」整个拆掉，改成授权式。** 起因：插件原本每小时自己去 PyPI 拉一次 `jmcomic` 新版，**直接覆盖 `vendor/`，不问任何人**。而插件是进程内加载、跟主程序同权限、没有沙箱 —— 上游一旦被投毒，下一次检查就把恶意代码写进服务器。

改后的行为：

- **不再有任何后台自动检查**，也不再自动安装。定时任务、自动覆盖逻辑全部删除。
- **只读检测**：敲任意常规命令时顺带查一次上游版本号，10 分钟节流，断网静默跳过，绝不阻塞命令。有新版就在回复末尾提示一行。
- **四个新命令**：`jm更新`（下载到临时目录 + 静态审查，不装）、`jm安装`（确认后覆盖）、`jm跳过`（跳过这版）、`jm放弃`（清临时）。
- **审查报可疑就拒绝安装**：危险调用、陌生外联地址、安装期钩子 `.pth`、上传者换人，中任一条都算可疑，`jm安装` 会被拒，要走 `jm强制安装` 才放行。
- **防偷换**：审查过的版本和实际要装的版本对不上，直接停手。
- **私有依赖 `curl-cffi` 同样改成授权式**：原来缺了就自己 pip 装，现在缺了只报缺，走 `jm依赖` 系列命令 —— 先列出版本和发布日期，你挑一个，下载 + 审查 + 确认才装。装的时候还会拿 PyPI 官方 sha256 比对，对不上就拒装。
- **配置面板**：移除了已失效的 `auto_update` 开关。

> **审查能力边界，说清楚**：这是**读代码**，不是杀毒。服务器上没有杀毒引擎，也认不出「已知病毒」。能查的是源码改动、文件清单、外联地址、安装期钩子、以及官方哈希比对。`curl-cffi` 的核心是编译好的 `.so`，里面写了什么读不出来，那一环只能靠来源可信。

### v1.1.0

搜索、榜单、按 ID 下载，长图 / zip / pdf 三种格式交付，任务可查可取消，内嵌依赖自包含。

## 常见问题

**Q：提示缺少私有依赖？**
A：2026-10-04 起 `curl-cffi` 不再自动安装。敲 `jm依赖` 看可选版本，再敲 `jm依赖 <版本号>` 下载审查，最后 `jm依赖 装`。

**Q：下载失败/搜索失败？**
A：禁漫接口偶发波动，稍后重试；也可检查服务器网络。

**Q：服务器会不会被下载堆满？**
A：不会。交付完成后服务器上的文件立即删除。
